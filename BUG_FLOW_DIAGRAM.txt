SUMMARY
================================================================================

The bug is a FLOW LOGIC ERROR, not a CONFIGURATION ERROR:

  Configuration:     ✓ Correctly set (6 confirmations required)
  Plugin methods:    ✓ Correctly implemented (return right values)
  Lock checking:     ✓ Correctly done (uses right minConf per stage)

  Stage transition:  ❌ BROKEN (doesn't clear or re-verify locks)

Result: Locks set in COLLECTION stage (minConf=2) bypass WAITING stage
validation (minConf=6) and allow premature SWAP execution.

Severity: CRITICAL - Security/finality issue

Fix time: 5-10 minutes (Option A) or 20-30 minutes (Option B)
