OTC Broker Admin Dashboard

Features

  • Simple email/password authentication with session management
  • Dark theme with clean, modern Bootstrap 5 UI
  • Deal list with sortable columns and color-coded stages
  • Detailed deal view with live escrow balances
  • Manual spend functionality for emergency operations
  • Account balance monitoring for tank and operator wallets
  • Mobile responsive design
  • Server-side rendered HTML (no complex frontend framework)

Tech Stack

  • Express.js for routing
  • Bootstrap 5 from CDN
  • Cookie-based sessions
  • Template literal HTML rendering
  • No build step required for frontend

Quick Start

# 1. Install dependencies
npm install cookie-parser

# 2. Set environment variables
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=secure-password

# 3. Integrate into rpc-server.ts
import cookieParser from 'cookie-parser';
import { setupAdminRoutes } from './admin-routes';

this.app.use(cookieParser());
setupAdminRoutes(this.app, this.db, this.pluginManager);

# 4. Start server
npm run dev

# 5. Navigate to
http://localhost:8080/admin/login
1. Login Page
Route: GET /admin/login
Features:
  • Clean centered design with gradient background
  • Email and password fields
  • Error message display (if invalid credentials)
  • Session created on successful login (24-hour duration)
Default Credentials: Set via ADMIN_EMAIL and ADMIN_PASSWORD env vars
