HOW THE FIX WORKS
  
  1. Detect if coinbase transaction (has vin[0].coinbase)
  2. Convert hex to bytes
  3. First byte = block height length (1-9 bytes)
  4. Following bytes = height in little-endian
  5. Convert to integer and use for vesting determination
  
  Example: "0333b502"
    - Byte 0: 03 = 3 bytes
    - Bytes 1-3: 33b502 (little-endian) = 177,459
